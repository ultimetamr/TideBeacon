## 2. 背景与问题

- **一句话需求**：为 PICO Spatial SDK Stage 设计一段无需解释即可跟随的中文视觉—空间音频呼吸节奏体验，让用户通过远处灯塔与光环的周期变化，在 2、4 或 6 分钟内自主完成一次非医疗性质的节奏练习。
- **目标用户**：能够佩戴 PICO 设备并使用手柄的中文用户；包括希望短时安静体验、但不愿阅读长说明的初次用户与复访用户。
- **使用场景**：室内安全区域，用户主动开始短时体验；环境可能有一般背景噪声，因此视觉节奏本身必须独立可理解。
- **佩戴姿态**：默认坐姿或原地站姿；不要求走动、转身或大幅身体动作。
- **频率与时长**：单次 2/4/6 分钟；频率由用户自定，不形成连续打卡压力。
- **空间必要性初判**：节奏由正前方远处灯塔、环状尺度变化、环境纵深和定向空间音色共同表达；与 2D 屏幕相比，用户无需持续读取仪表，方向、距离、尺度与包围感可共同承载“扩张/收回”。最终空间价值仍须在 Stage 6 与 2D 反事实逐项论证。

## 3. 关键时刻

- **屏幕难以等价表达的时刻**：吸气时光环从灯塔周围向用户视野舒缓扩张、空间音场同步展宽；呼气时两者共同收回灯塔方向，节奏在尺度与距离感中被直觉识别。
- **空间需求（非容器决策）**：设置与选择需要稳定的平面菜单；练习需要具方向/距离/深度的 Stage；暂停操作应位于舒适可达区。具体容器、attachment 与层级由后续空间结构阶段决定。
- **进入路径（行为需求）**：首次先以单一稳定界面呈现灯塔缩景、光环和唯一一句“光扩张时吸气，光收回时呼气。”；具体空间模式与容器选择为 Stage 09 决策；用户主动配置后才进入练习。

## 5. 意图定义（冻结项 rev1）

- **领域 / 子领域**：沉浸式节奏引导 / 纯视觉与空间音频的呼吸节奏体验。
- **风险等级**：低至中。没有诊断或生理数据风险，但存在眩晕、闪烁不适、音频爆音、暂停恢复错相与误导性健康语言风险。
- **空间转换需求**：选择界面保持稳定且不强制沉浸；练习的沉浸空间仅由用户明确开始后进入。具体 Shared/Full 与容器组合由 Stage 09 决定。
- **核心场景**：首次理解提示；选择 2/4/6 分钟；选择海面/云层/沙丘；选择 BreathPattern；运行练习；暂停/恢复；重新开始；退出确认；完成；可选本地记录。
- **核心任务**：理解光环映射；配置一次练习；跟随周期；中断后无跳变地恢复；安全退出或重新开始；识别完成状态；自主决定是否保留本地记录。
- **关键决策**：时长、场景、节奏、开始、暂停/恢复、退出、重开、完成后是否本地记录。
- **用户事实**：不检测呼吸、不接麦克风、不评分；完成后记录可选且本地。**有界产品决策**：MVP 不引入 AI、网络或额外传感器，理由是这些能力不服务核心节奏且扩大隐私/失败面；本地记录字段暂定完成时间、时长/场景/节奏，须在实现前做最小化复核。
- **协作**：无多人、无跨设备协作。
- **内容与声明边界**：不是医疗或健康诊断产品；不评分、不评价呼吸“正确性”、不使用治疗/改善/疗效语言。

## 7. 质量契约（冻结 rev1）

- **QC-OUTCOMES 必须业务结果**：
  1. 用户在首次进入后 10 秒内仅凭灯塔、光环和“光扩张时吸气，光收回时呼气。”说出正确映射；不要求阅读额外说明。
  2. 用户仅用手柄完成时长、场景、节奏选择并开始 2 分钟流程。
  3. `BreathPattern` 四相、空间音频、环动画、倒计时和循环完成事件由同一暂停感知单调时间轴派生；刷新率不改变相位或结束时刻。
  4. 用户暂停后动画、声音、倒计时保持同一快照；恢复不跳相位，音量在 300–500ms 内平滑淡入且无可感知爆音。
  5. 用户可随时暂停、恢复、重开或退出；退出与重开有明确确认/可撤销路径；系统挂起/恢复与用户暂停语义一致。
  6. 2/4/6 分钟、海面/云层/沙丘、至少三种 BreathPattern 可选；场景为程序化低多边形占位。
  7. 完成只显示“完成一次练习”和可选本地记录，不显示分数、连胜、医学或疗效语言。
  8. 应用不检测呼吸、不接麦克风、不读取生理数据、不使用 AI、不评分；无网络需求。
- **QC-EFFICIENCY 成功/效率标准**：首次映射理解目标 ≤10 秒；单项三选一 ≤5 秒；从选择页到开始 ≤30 秒；暂停反馈下一渲染帧可见；120.000 秒的 2 分钟流程在时间轴容差 ±1 个显示帧内进入完成，逻辑时刻不得按帧率漂移。
- **QC-RISK 风险与不可失败项**：禁止自动相机移动、强闪烁、无限脉冲和高速粒子；退出必须稳定可达；暂停/系统挂起不得推进时间轴；恢复音频必须从静音包络淡入；完成记录默认不强制；严禁健康诊断、疗效、正确性评分语言。
- **QC-WINDOW 行为约束**：任一时刻只有一个主要任务焦点；练习世界为主时暂停层不得形成并列主界面。Planar/Stage/空间模式/层级的具体选择留给 Stage 09。
- **QC-COMPONENT 领域注册表**：UI 核心组件为 `SessionChooser=C2 ScenePicker+C3 DurationPatternPicker`、`BreathHalo=C4`、`PauseControl=C5`、`CompletionMarker=C6`，均具八段结构。`UnifiedTimeline` 与 `SpatialAudioEnvelope` 是无 UI 的运行时服务：前者输出 phase/progress/remaining/cycleIndex/paused，后者消费同一 elapsed 并提供 pause freeze、normal400ms/performance600ms resume envelope；二者以 interaction §13.4 测试契约而非视觉 anatomy 交付。
- **QC-DATA 实时数据可信**：无网络实时数据；时间值来自本地单调时钟，配置在会话开始冻结；本地记录标注“仅此设备”，写入失败不阻止完成；显示值有中文 fallback，不回显机器枚举。
- **QC-PICO 平台与空间硬约束**：遵循 `official-rules.json@2.2.0`：Stage 显式进入且稳定退出；Shared/Full Space 组合合法；Reduce Motion、文本缩放、Controller Fallback；Planar sizing 完成基线/FOV/视距/default-min-max/reflow 链；目标 ≥56×56dp，正文 ≥12dp；附件先做 None/InlineControl 对比；不把 CSS 效果宣称为 PICO 系统材质。
- **QC-ORIGINALITY 原创性**：落实 UXR §3A `OPP-1..5`——灯塔稳定远距锚点、统一时间轴、无检测极简边界、单句首屏、冻结恢复；只吸收竞品“可配置、环境选择、视觉节奏明确”的需求，不复用其布局、状态序列、组件组合或视觉风格；至少比较三种结构性不同假设。
- **QC-ACCEPTANCE 设计/可读性/下游实施验收**：六份核心文档最低完整性全 pass；17 阶段 trace 顺序完备；六个独立评审 invocation 证据齐全；状态/转换/组件事实全部进入 Preview Manifest 与五张映射表；自包含 `preview.html` 可触发首次/选择/运行/暂停/确认/完成/响应式/Reduce Motion；时间轴测试使用合成采样矩阵 60/72/90/120Hz（不代表设备支持声明）并覆盖应用暂停恢复；真机舒适、音频波形、手柄与截图由下游实现阶段验证，本设计不得伪称已验证。
